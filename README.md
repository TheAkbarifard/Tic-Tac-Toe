## 🌐 English

A clean, modern, dark-themed desktop implementation of the classic Tic-Tac-Toe game for **two local players**, built using Python's built-in `tkinter` library. 🚀

### ✨ Features
- **🎨 Sleek Aesthetics**: A dark theme designed to look modern and elegant.
- **📊 Scoreboard Tracking**: Tracks the total wins for Player **X** and Player **O**.
- **🔄 Score Reset**: A dedicated **Reset Scores** button located directly next to the score indicators.
- **⚡ Click-to-Restart**: When a match finishes (win or draw), simply click anywhere on the window to immediately start a new match. No need to click "Restart Game".
- **🎨 Visual Feedback**: Distinct color-coding for Player **X** (Blue) and Player **O** (Orange).
- **🕹️ Responsive Controls**: Smooth grid layout with interactive tiles.
- **🏁 Victory & Draw Detection**: Automatically detects row, column, and diagonal matches, or when the board is full.
- **🔄 Restart Game Button**: Start a new match at any time using the button at the bottom.

### 📋 Requirements
- Python 3.x 🐍

### 🚀 How to Run

1. **Clone the repository** or download the code:
   ```bash
   git clone https://github.com/TheAkbarifard/Tic-Tac-Toe.git
   ```
2. **Navigate** to the project directory:
   ```bash
   cd Tic-Tac-Toe
   ```
3. **Run the script**:
   ```bash
   python ticTacToe_gui.py
   ```

## 🇮🇷 فارسی

یک پیاده‌سازی دسکتاپ تمیز، مدرن و با تم تاریک (Dark Mode) از بازی کلاسیک دوز برای **دو بازیکن به صورت محلی (آفلاین)**، ساخته شده با استفاده از کتابخانه پیش‌فرض پایتون `tkinter`. 🚀

### ✨ ویژگی‌ها
- **🎨 ظاهر شیک و مدرن**: تم تاریک طراحی شده برای ظاهری زیبا و کاربرپسند.
- **📊 جدول امتیازات**: ردیابی تعداد بردهای بازیکن **X** و بازیکن **O**.
- **🔄 بازنشانی امتیازها**: دکمه اختصاصی **Reset Scores** قرار داده شده در کنار نمایشگر امتیازها.
- **⚡ کلیک برای شروع مجدد**: پس از پایان بازی (برد یا مساوی)، تنها با کلیک روی هر نقطه از پنجره بازی را دوباره شروع کنید (بدون نیاز به کلیک بر روی دکمه پایین صفحه).
- **🎨 بازخورد بصری رنگی**: رنگ آبی اختصاصی برای بازیکن **X** و رنگ نارنجی برای بازیکن **O**.
- **🕹️ کنترل‌های تعاملی**: دکمه‌های شبکه‌ای بزرگ و پاسخگو.
- **🏁 تشخیص خودکار برنده و مساوی**: بررسی خودکار ردیف‌ها، ستون‌ها و قطرها برای تعیین برنده.
- **🔄 دکمه شروع مجدد**: شروع یک بازی جدید در هر زمان با دکمه پایین پنجره.
